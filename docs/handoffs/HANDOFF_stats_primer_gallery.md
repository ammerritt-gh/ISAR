## Framing (agreed, use verbatim as the primer's spine)

Every ISAR fit answers three separate questions, in order:

1. **What do we minimize?** Baker–Cousins Poisson likelihood cost (not Neyman, not Pearson).
2. **Which model wins?** Akaike weights over candidate models.
3. **How wide is the answer?** The interval ladder: Hessian (fast, never certifies) → profile →
   bootstrap (certifying) → Bayesian (planned, not built).

Vocabulary rules for the primer (docs discipline):
- Bootstrap = frequentist-by-simulation. Bayesian = posterior **credible** intervals ("confidence"
  belongs to the frequentist side). Never blur them.
- "Bayesian" is used ONLY where earned: branch assignment posterior (`assignment_entropy`) and
  soft priors (`prior_omega`/`prior_sigma` → MAP fit). Error bars are bootstrap/profile,
  frequentist. Bayesian intervals carry status **Planned**. No "vaguely Bayesian" anywhere.
- Every capability statement carries Implemented / Partial / Planned status.

able to reproduce the argument, that is the entire trust model.

## The figures (the seminar deck)

1. **`three_questions.svg`** — the pipeline map: minimize (Baker–Cousins) → select (Akaike) →
   certify (interval ladder with Bayesian dashed/planned). Static, no data.
2. **`cost_bias.png`** — THE Neyman argument. Same synthetic low-count phonon scan fit three ways
   (Neyman / Pearson / Baker–Cousins), overlaid on the data; plus a second panel: fitted amplitude
   bias vs mean counts-per-point from an ensemble (N≥500 per count level), showing Neyman biasing
   low, Pearson high, Baker–Cousins unbiased, all converging at high counts. This is the "your
   default lies at exactly the count rates you measure phonons at" figure.
3. **`coverage_table.png` + `coverage_curve.png`** — THE Hessian argument, and the centerpiece.
   Ensemble of synthetic scans with known ω₀ (reuse the scorecard machinery — it already computes
   coverage/pulls). Report observed 68% coverage for Hessian vs profile vs bootstrap intervals,
   overall and vs counts. Expected result: Hessian materially under-covers, bootstrap ≈ nominal.
   Caption states it as an experimental result, with N.
4. **`wall_figure.png`** — Γ-at-bound geometry with REAL data: the likelihood/parabola schematic
   panel plus two actual MVP-16 bootstrap ω₀ histograms side by side — one healthy (wide,
   asymmetric, `interval_reliable=True`) and one degenerate (collapsed spike, the `[3.15,3.15]`
   pathology, `interval_reliable=False`). Caption: "zero width is degeneracy, not precision; this
   is what the flag marks."
5. **`akaike_example.png`** — a real (or reference-workspace) two-peak candidate scan: one-peak
   and two-peak fits overlaid, AIC and Akaike weights annotated. Caption: the second peak must buy
   its parameters in likelihood; nobody eyeballs shoulders.
6. **`branch_posterior.png`** — one genuinely ambiguous scan: branch posterior bar pair
   (acoustic/optic) + `assignment_entropy`, next to an unambiguous one. Caption: entropy is the
   honesty meter; near ln 2 means "coin flip — do not deliver."
