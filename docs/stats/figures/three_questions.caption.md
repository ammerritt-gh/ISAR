**Every results row answers one of three questions** — a static map of the pipeline: MINIMIZE (which parameters, via Baker–Cousins), SELECT (which model, via Akaike weights), CERTIFY (what uncertainty, via a four-rung interval ladder — Hessian → profile → bootstrap → Bayesian); the columns list the actual results.csv columns each stage produces. The Bayesian rung is drawn dashed because it is diagnostics-only: it runs under --errors bayes but never certifies, so the bootstrap below it remains the authoritative interval. *What good looks like:* you can trace any number in a results row back to the question it answers and to the rung that produced its error bar — nothing floats unattributed.

*Terms:* **Baker–Cousins** — the Poisson maximum-likelihood cost ISAR minimizes instead of a χ²; **ladder** — intervals ordered cheapest-to-most-honest; agreement across rungs is the trust signal (hesse_trusted, interval_reliable)
