Quick guide

ISAR reads your scans, fits every spectrum and tells you where to look. It never deletes a file and never changes your data: what you see here is a first look to steer by, and you review everything afterwards.

1. Drop your data

Drop the data files, or the folder they are in, on the box that says Drop data files or a folder here, or press Add data files… or Add data folder…. ISAR makes an experiment folder named after your files and reads them. The files stay where they are and must stay available. To read more later use Add data ▾. The line under the experiment name tells you how many scan sets and analyzers were read.

2. Choose the resolution curves

BL43LXU data are fitted with the measured resolution curves. The setup area has two buttons, Resolution curves (rf)… and gpi files…. Each shows a green check when its folder is good and a red cross when it is not; hover over it for the folder's path and the reason. If the setup area says No resolution curves yet, or the Resolution curves (rf)… cross says no resolution folder is set or that analyzers have no resolution curve, press it and pick the folder that holds the curves. ISAR saves the choice with the experiment. A folder you have just picked stays crossed, with the reason the resolution folder changed, until the next import (Add data) checks it; picking the same folder again does not check it, so add the data instead. ISAR also looks for a folder named rf next to your data, and for a gpi_files folder.

3. Fix what needs attention

Needs attention lists what is missing or unreadable. Open a group, tick the scan sets it concerns, enter the value (a temperature, for example) and press Save my value. A value you enter is used instead of the file's; the files are never changed. Without a value ISAR can still fit, on a stated stand-in.

4. Queue the analysis

Press Fast-pass all ready in the setup area, beside the count of analyzers that are ready. Every ready analyzer file without a current fast pass joins the fast queue in the Processing panel, and ISAR works through the queue on the cores you gave it (Config ▸ Cores for analysis…). With Fast-pass new scans as they arrive on, newly read files join by themselves. To fit one analyzer more thoroughly, select it in the scan list and press Deep pass; a deep pass is only ever started by you. Pause starts nothing new until you press Resume; the stop button beside a running analyzer stops that one and ✕ takes a waiting one out. An analyzer ISAR cannot fit yet is listed as held with the reason; add it again once what it needs exists. Results already stored stay.

5. Read the scan list

Each row is a scan set; open it to see its analyzers. The hkl column shows each analyzer's hkl in r.l.u. when ISAR has one (hover for its source); |Q| (nm⁻¹) is under Columns ▾. On BL43LXU the gpi and rf columns show a check or a cross for each analyzer. The Fast pass and Deep pass columns appear by themselves once a result exists. The colour dot and the word say how settled a result is; hover a word for what it means, or see Help ▸ What the status words mean. Select an analyzer row and press Open inspector (or double-click it) to see the file's facts, your values, and the plot. The Anchor column marks the spectra you trust, Flag marks the ones a person should review, Lock marks a fit no batch may change, and Inter-spectra fit says which fit ISAR uses for each spectrum. Select spectra and right-click to choose Set as anchor or Remove anchor.

6. Refine fits with neighbours (optional)

Once you have spectra you trust, open the Inter-spectra fitting box in the Processing panel. Add selected scans as anchors adds the selected scans to the Anchors list, and Remove selected anchors takes them out. Choose Spread in q, Spread in T or Spread in q and T, then press Start anchored batch: it refits the spectra around the anchors, ring by ring. To refit spectra together, select them in the scan list and press Start simultaneous batch on the selection. Each batch is one row in the queue. A Start button stays greyed out, with the reason as its tooltip, until its batch can run. Open a spectrum in the Scan(s) view and press Inter-spectra fitting to choose among its fits: the fast solo fit, then the refits grouped by batch. Make authoritative makes the chosen fit the one ISAR uses, and Lock this fit stops any batch refitting it (Unlock releases it). Waterfall of fits draws the spectrum's fits one above another. A refit lists its reasons for review with their severity, and its error bars are conditional on the neighbours. Nothing starts by itself. The penalty settings are under Config ▸ Inter-spectra fitting settings….

7. Take the results away

Export results… in the bottom bar writes the results to a new folder and tells you where it is. Save experiment copy… copies the whole experiment folder. Both leave your experiment as it was.

If something looks wrong, Help ▸ Open GUI Log Folder opens the log.
